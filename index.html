IMG Chest helper for Mudae

This app helps with adding custom images to a character in Mudae: upload your pictures (converted to PNG automatically) and grab each picture's link, already separated the way the bot wants.

Make sure to have an account already created on IMG Chest. You'll need an API token to use the app.

An API token can be requested here
API token saves in Local Storage after the first successful grab or upload. It should auto set after the first time but can be changed at any point anyways

Add images in any format (JPG, WEBP, GIF, BMP, AVIF, SVG, HEIC, TIFF...). Each one is converted to PNG in your browser, then everything is uploaded as one new IMG Chest post. You can also paste images from the clipboard.
